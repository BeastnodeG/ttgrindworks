# Toontown: The Grindworks
Alders mods for [Toontown: The Grindworks](https://github.com/ToontownGrindworks/grindworks)

## Installation
Download the zip for the mod you want under [releases](https://github.com/BeastnodeG/ttgrindworks/releases)
(Do not download the source code)

**Windows / Linux:**  
Create a `mods` folder next to your `ToontownTheGrindworks.exe` and place the desired mod `.zip` file(s) into it. *(Do not extract the zip.)*

**macOS:**  
Create a `mods` folder in the `/Applications` folder and place the desired mod `.zip` file(s) into it. *(Do not extract the zip.)*
